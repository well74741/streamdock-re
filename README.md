# Stream Dock M18 控制台

自研 Stream Dock M18 驱动：一个本地图形控制台，**不经过官方 Stream Dock 软件**，自己接管设备的按键、屏幕和 24 颗灯珠。

方案细节见 [方案-StreamDock-M18自研驱动.md](方案-StreamDock-M18自研驱动.md)。

## 打开方式

**装好的版本**：双击安装包 `M18Console-Setup-<版本>.exe`，装完开始菜单和桌面上都有「Stream Dock M18 控制台」。

**从源码运行**：双击 `启动 M18 控制台.bat`。

会启动本地服务（`127.0.0.1:8642`）和一个 Edge 应用窗口（无地址栏）。重复启动只会复用已有实例，并替换掉旧窗口。

## 安装包

完整的打包与安装步骤见 [docs/打包与安装指南.md](docs/打包与安装指南.md)。

双击项目根目录的 **`打包.bat`**（缺 Python / 依赖会引导安装），或：

```bash
python packaging/build.py      # 先检查环境，缺 Pillow / PyInstaller 会询问后自动安装；需要 ws-sdk/ 已就位
```

产物：`dist/release/M18Console-Setup-<版本>.exe`（单文件，约 44 MB，版本号在 `app/version.py`）。

- 自带 Python 运行时和官方 WebSocket SDK，对方电脑**不需要装 Python**
- 装到当前用户目录（`%LOCALAPPDATA%\Programs\M18 Console`），**不需要管理员权限**
- 开始菜单 / 桌面快捷方式，「设置 → 应用」里可卸载；卸载时可选是否保留用户数据
- 用户数据（配置、场景、上传的图标、自制插件）在 `%APPDATA%\M18Console`，升级重装不丢
- 静默安装：`Setup.exe --silent [--dir 目录] [--no-shortcut] [--no-launch]`

对方电脑的要求：Windows 10/11 64 位、Microsoft Edge（系统自带）、M18 设备。
**不需要官方 Stream Dock 软件**：设备驱动用的是安装包自带的官方 WebSocket SDK。
装了官方软件时还能导入官方场景 / 图标包 / 插件；导入后的内容存在本地，卸载官方软件也不会丢：

| 内容 | 存放 | 官方软件卸载后 |
|---|---|---|
| 官方场景（含图标） | 导入时转换进 `%APPDATA%\M18Console\scenes`、`assets\uploads` | 照常可用 |
| 图标包 | 启动后自动备份到 `official-mirror\icons`（缩小到按键尺寸，约 70 MB） | 照常可用 |
| 第三方插件 + Node 运行环境 | 「同步官方」时选择备份，复制到 `official-mirror\plugins`、`node`（约 500 MB） | 备份过的照常可用 |
| 官方内置功能（打开 / 热键 / 文本 / 页面…） | 拖到按键时换成控制台原生动作 | 照常可用 |

- 安装包**自带 28 个官方「内置功能」插件**（OBS Studio、热点、热键、文本、页面、鼠标事件…，约 13 MB），
  对方不装官方驱动也能在侧栏「插件」里看到并使用它们。
- 首次运行会自动装好默认场景：**相册1**（自带 12 张示例图，可换成自己的）和 **音乐控制台**，加上「自定义」共三个。
  之后自己删掉的场景不会再自动出现。

安装包没有数字签名，首次运行 Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可。

## 架构（重要）

```
浏览器 UI ──HTTP/SSE── server.py ──WebSocket── StreamDockWebsocketSDK.exe ──HID── M18
```

- 设备 IO **全部走官方 WebSocket SDK**（`ws-sdk\StreamDockWebsocketSDK.exe`，默认端口 9002）。
  早期版本直接用 `transport.dll` 操作 HID，**收不到按键**——原因是设备必须先收到 `read` 命令
  才会开始上报输入，而 transport.dll 没有暴露这条命令。
- 连接成功后发给 SDK 的第一条设备命令必须是：
  ```json
  { "event": "read", "path": "<设备path的base64>", "payload": {} }
  ```
- 设置按键图片的字段是 **`imgData`**，且必须是带前缀的 data URI：
  `data:image/jpeg;base64,...`（写成 `imageData` 会被 SDK 静默忽略，表现为"命令发了但屏幕不亮"）。
- 其余命令：`setBrightness` / `setLEDBrightness` / `setSingleLedColor` / `refresh` / `clearAllIcon`。

## 当前功能

| 页签 | 内容 |
|---|---|
| 自定义控制台 | 15 个键格 + 外圈 22 颗灯珠 + 正面 2 颗 + 3 个导航键；右侧「灯光」「壁纸」两区 |
| 设备 | 设备信息、输入事件日志、重新连接、退出 |

- **按键**：点选键格后在下方编辑，可绑定
  - 打开路径（exe / 快捷方式 / 脚本 / 文件夹 / 文档）
  - 打开网页
  - 热键（支持「录制热键」，如 `ctrl+shift+s`）
  - 导航（上一页 / 下一页 / 主页 / 跳到第 N 页）
- **拖入程序**：把 `.exe` / 快捷方式拖到按键或编辑区，直接变成「打开这个程序」，
  **并自动用程序自己的图标当按键画面**。路径是自动认的：从资源管理器拖过来时浏览器会带上
  文件地址，直接用；快捷方式会解析出它指向的程序；只有地址都拿不到时，才按文件名去
  `Program Files` / 桌面 / 下载这些常见位置找一遍。**只有在全都找不到时**才弹一次
  「选择程序」窗口让你手动指一下。
- **按键外观**：可设标题文字（中文自动适配字号、最多两行）+ 文字颜色 + 按键底色；
  拖入整张图片则优先显示图片。
- **多页面**：每页独立的按键图片、动作和样式；支持新建 / 改名 / 删除，导航键切换，控制台页码同步。
- **文件夹**：动作类型选「文件夹」，按下进入子页（子页左上角 11 号键是返回，可多层嵌套）；
  编辑区「打开文件夹编辑」进去放按键，页码行显示路径和「返回上级」。翻页只在主页面之间走。
- **场景分享**：场景右键「导出场景…」得到一个 `.m18scene` 文件（含图片和用到的自制插件），
  别人点场景栏的 ⇩ 或把文件拖到场景列表即可导入；只含按键内容，不会改对方的灯光、壁纸等全局设置。
- **灯光**：常亮 / 彩虹 / 呼吸 / 流光（默认）/ 渐变 / 涟漪 / 自定义，24 颗逐颗上色，支持反向、亮度、速度（最高 10×）；
  涟漪 = 平时全灭，按下按键时从按键位置向四周扩散一圈光。灯光设置重启后保留。
- **待机**：闲置 3–300 秒（默认 300）后整屏铺壁纸，设备按键立刻回到键面；界面操作不会打扰待机。
- **自动息屏**：待机卡片第一行的开关，滑条 15 秒–30 分钟（15–1800 秒）；空闲到点就把 15 个键刷黑、背光降到 0，
  按键通道还醒着，按任意键（含三个导航键）立刻点亮回键面，在控制台里点任何东西（换场景、调灯光、改设置…）也会顺手唤醒。
  唤醒后回到息屏前那个场景（不会顺势滑进待机画面）；在控制台里直接点别的场景会先亮屏再切过去。
  **和「待机画面」二选一**：开一个另一个自动关掉。
- **待机画面（壁纸 / 幻灯片）**：一张卡片两个页签，铺放方式、缩放、间隙、亮度共用；可选闲置后显示壁纸还是幻灯片。
  幻灯片：拖入 / 选择多张图片，整页 15 键拼成一张大图；自动切换 2–60 秒，过渡有淡入 / 滑动 / 擦除 / 马赛克。
  壁纸和幻灯片都只是待机画面，不占场景列表；播放时 ◀ ▶ 翻照片，按其他键回到当前场景。
- **相册场景**：新建场景时能选「相册场景」，一套相册就是一个场景，可以建多套。
  选中它，按键编辑区会换成图片编辑区：拖入图片进下方列表、单击看某张、拖动排序，幻灯片时长和过渡效果（淡入 / 滑动 / 擦除 / 马赛克）单独设置，
  预览下面的「铺放」（填充 / 完整 / 拉伸）和「间隙」也只对这个相册场景生效；点缩略图换图片时，控制台预览和 Dock 都会跟着换，
  「删除图片」删掉预览框里这张（只从场景里移除，文件还留在 `assets/uploads/`）。
  图片列表和预览框里对着图片右键，可以「打开图片位置」直接跳到文件所在目录。
  在 Dock 上它就是整屏轮播：点任意屏幕键切到**下一个场景**，◀ ▶ 翻上/下一张图片，中间键回切过来的那个场景；
  三个导航键默认就是「上一页 / 主页 / 下一页」，点它们可以像普通键一样进按键编辑区改掉；
  相册场景只有图片、没有图片时切不过去（会提示先加图）。翻页、新建页这些按钮在相册场景里是隐藏的，新页只在拖入图片时出现。
- **场景排序**：场景列表里长按某个场景 0.45 秒就能上下拖动排序，「下一场景」按这个顺序轮转。
- **场景停用**：每个场景右侧的小开关，关掉后「下一场景」和关联程序自动切换都会跳过它。
- **屏幕方向**：0° / 90° / 180° / 270°，竖放或倒放 Dock 时所有图标（含动图、插件画面、壁纸）自动转正，
  控制台预览跟着转向但按键大小不变。
- **壁纸**：支持把图片直接拖到预览区替换；预览上可拖动平移；切换填充方式自动归零偏移。
- **热插拔**：拔掉自动等待，插上自动重连并重推画面、灯光、按键。
- **官方场景**：首次启动自动把官方驱动里 M18 的全部场景（含预设包、多页）转换进场景列表（◈ 标记），
  图标（含官方加密的 `.mbg` 动图）、标题、网址 / 程序 / 热键 / 宏 / 媒体键 / 亮度 / 场景切换都会还原；
  时钟、天气等官方插件控件只保留图标。删掉的官方场景不会再自动出现。
- **图标库**：直接读取官方驱动下载的图标包（按包分组、展开时才加载），点选或拖到按键上即可使用；
  用到的图标会复制一份进用户数据目录的 `assets/uploads/`，官方删了图标包也不影响。
  侧栏分两段：「我的图标」在前（自己用裁图工具做的），下面是「官方图标包」。
  **点一下图标只是临时预览**（按键格子虚线框、功能行显示「临时预览…」），点「保存」才真正写进按键；
  换一个键、点空白处或按 Esc 都会还原。
- **相册分类**：侧栏里独立的一块（在「图标库」下面），专门放图片（壁纸、幻灯片、裁图源图都可以收进来）。
  添加方式和其它分类一样：拖图片到这块里（拖进来时整块会亮一圈蓝框）、点右上角「＋ 添加」多选，都行。
  在壁纸 / 幻灯片里选过的图会自动收进来；右键任意一张能「设为壁纸 / 加到待机幻灯片 / 打开图片位置 / 从相册删除」
  （这个菜单和图标库里的右键菜单是同一个，样式统一），也可以像其它图标一样直接点选或拖到按键上（存的是 `lib:` 引用）。
  侧栏只加载 168px 的缩略图，原图再大也不会把界面拖卡。
- **裁图工具**：控制台右下角的 `✂ 裁图工具`。把一张图片拖进去，右边按屏幕排版排成 5×3 共 15 张（上排是 11–15 号键、
  中间 6–10、下排 1–5），铺放方式（填充 / 完整 / 拉伸）和间隙（默认 27）可调；点「保存到「我的图标」」就生成一个以图片名命名的
  图标包，存进 `assets/myicons/<图片名>.sdIconPack`。支持动图：GIF 会逐帧裁好，左边预览和右边 15 张都会直接播放。
- **插件**：内置插件宿主，兼容官方 / Elgato 插件协议，直接运行官方驱动里装好的插件：
  Node.js 插件用官方自带的 `node20.exe`，exe 插件直接拉起，网页插件跑在后台无头 Edge 里。
  把侧栏「插件」里的动作拖到按键上即绑定；按键编辑区「插件设置」打开插件自带的设置页。
  插件进程日志在 `app/plugin-data/logs/`。官方「内置」插件（多媒体、热键等）由控制台自己的动作实现。
- **动作类型**：打开路径 / 网页、热键、双状态热键、媒体键、屏幕亮度、输入文本 / 密码（支持中文）、
  鼠标操作、关闭程序、切换到场景 / 返回上一场景、播放音效、宏（多步）、导航、控制台。
- **控制台动作**：「控制台」类型可以让按键控制本程序自己——屏幕开关（息屏 / 亮屏）、
  屏蔽按键开关（屏蔽后其它键都不响应，只有设了「屏蔽按键开关」的那个键还能按，再按一次恢复；
  但**涟漪灯效照常亮**，屏蔽的是动作不是光）、
  灯光开关（关掉再开回到原来的效果）、灯光效果切换（在六个灯效之间轮换）。
- **短按 / 长按 / 双击**：每个键三种触发可分别设动作（长按 0.5 秒、双击间隔 0.3 秒）；只设短按的键零延迟。
- **场景关联程序**：场景右键「关联程序…」，前台切到该程序时自动切过去，离开后切回原场景。
- **同步官方**：侧栏「同步官方」会先问同步哪一块——全部同步 / 只同步场景 / 只同步图标包 / 只同步插件；场景还能选「只加新的」或「全部重导」，插件（约 500 MB）要单独确认。
  这台电脑没装官方 Stream Dock 驱动（或装在别的位置）时，点「同步官方」会直接提示「没有检测到官方驱动」，
  自带的图标包、28 个内置插件和默认场景照常可用。
- **自制插件**：主页下方「自制插件」里用几行 JavaScript 写插件（带计数器 / 时钟 / 网络数据 / 开关模板、
  API 速查、运行日志、保存即热重载）；保存在 `app/custom-plugins/`，是标准 `.sdPlugin`，
  出现在侧栏「自制插件」里，拖到按键上使用。
- **接入 AI 智能体（MCP）**：「自制插件 → 接入 AI」一键复制 Codex / DeepSeek Harness / Claude / Cursor 的配置。
  AI 能写插件、绑到按键、模拟按键、看键面截图和日志，自己测到能用为止（16 个工具，见 [AGENTS.md](AGENTS.md)）。
  插件开发指南：[app/plugin_guide.md](app/plugin_guide.md)。ChatGPT 网页版连不到本机，请用 Codex。
- **托盘常驻**：关掉控制台窗口不会退出程序，控制台缩到系统托盘继续跑（第一次会弹一条提示）。
  双击托盘图标重新打开窗口，右键菜单可「打开控制台 / 退出控制台」；退出时会把后台 SDK 一起收掉。
  不想要这个行为就去「更多设置 → 关窗口后收进托盘」把它关掉，之后点窗口的关闭按钮就是直接退出。
- **场景保护**：切场景前会先保存「自定义」里的改动；如果某个场景里没有任何图片和动作（空场景），
  切换会被拒绝并提示，避免一切场景就把刚摆好的画面清空。

## 排错

- 日志：`app/server.log`
- 收不到按键：确认 `StreamDockWebsocketSDK.exe` 在运行，且连接后发过 `read`
- 屏幕不亮：检查 `setKeyImgData` 的 `imgData` 是否带 `data:image/jpeg;base64,` 前缀
- 界面打不开：删掉 `%LOCALAPPDATA%\M18Console\browser` 后重启
- 右键拖动会画出浏览器的手势线：控制台启动时会把 Edge 的「鼠标手势」策略关掉
  （`HKCU\Software\Policies\Microsoft\Edge` 的 `MouseGestureEnabled = 0`，见 Microsoft 的
  [MouseGestureEnabled](https://learn.microsoft.com/en-us/deployedge/microsoft-edge-policies/mousegestureenabled)）。
  想恢复 Edge 手势就删掉这个值或改成 1；它对这个用户下的所有 Edge 窗口生效。
- 图标库 / 插件索引为空：官方软件不在常见安装位置时，在 `app/config.json` 里加
  `"officialRoot": "X:\\你的路径\\Stream Dock"`（或设环境变量 `M18_SD_ROOT`）

## 官方插件兼容性

控制台自带插件宿主（`app/pluginhost.py`），能直接跑官方驱动 `plugins` 目录里的插件，按入口类型区分：

| 入口类型 | 数量（本机） | 情况 |
|---|---|---|
| `*.html`（网页插件） | 14 | 正常。宿主用**有窗口**的 Edge 在屏幕外跑，便签 / 待办这类 `window.open` 的弹窗会以独立窗口显示（窗口本身从任务栏隐藏） |
| `plugin/index.js`（Node） | 10 | 正常，用官方目录里的 `node\node20.exe`（找不到时用系统 `node`） |
| `*.exe` | 4 | 能启动；未签名的 exe 在装了火绒等安全软件的机器上可能被拦（表现为插件没反应，日志里没有「插件已启动」） |
| `*.cmd` / `*.bat` | 1 | 能启动（用 `cmd /c` 转发参数），但插件自己的脚本要配好才能用（ScriptDeck 这类） |
| 没有 `CodePath` | 1 | 跑不了：官方内置功能（如 ETS2 Hotkey），只能由官方驱动实现 |

需要登录 / 填密钥的插件（Spotify、OBS、YouTube、PR、GitHub-CI 等）能加载，但要先在按键的**设置页**里把账号、API Key 填好，否则只会显示离线。

## 安全

本地服务只接受本机控制台界面自己的请求：`Host` 必须是 `127.0.0.1`/`localhost`，
写操作必须同源且为 JSON。其他网页无法跨站调用 `/api/*`（例如偷偷给按键绑定程序）。
自己写脚本调用接口时，带上 `Content-Type: application/json` 即可。

## 从源码运行

仓库里**不含**以下第三方/本地内容，需要自己准备：

| 缺失项 | 说明 |
|---|---|
| `ws-sdk/` | 官方 WebSocket SDK（`StreamDockWebsocketSDK.exe` 及 DLL），从 Mirabox 官方 SDK 包里解压到项目根目录 |
| `app/config.json` | 首次运行会自动生成；也可复制 `app/config.example.json` 改名 |
| `app/assets/icons/` | 图标库由「同步图标库」从官方软件目录抓取生成 |
| `app/scenes/` | 场景数据，运行时生成 |

准备步骤：

1. 安装 Python 3.9+（勾选 Add to PATH），双击 `setup.bat` 自动装 Pillow
2. 把官方 SDK 的 Windows 包解压到 `ws-sdk/`（其中应有 `StreamDockWebsocketSDK.exe`）
3. 双击 `启动 M18 控制台.bat`（或 `python app/server.py`）
4. 浏览器会自动打开 `http://127.0.0.1:8642`

> 设备 IO 全部经过官方 WebSocket SDK，本仓库不包含其二进制文件。
