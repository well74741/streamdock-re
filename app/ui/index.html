自制插件

写一小段 JavaScript 就是一个插件；保存后出现在左侧「自制插件」，拖到按键上使用
图标
API 速查

事件：M18.on("事件", (key, payload) => { … }) willAppear 出现在屏幕上 · willDisappear 离开 · keyDown 按下 · keyUp 松开 · ready 插件启动

按键：key.setTitle(文字) · key.setImage(dataURL) · key.draw((g, size) => { … }) 用 canvas 画（size = 144） · key.showOk() · key.showAlert()

数据：key.settings 读取 · key.save({ … }) 保存（每个按键各一份，重启后还在）

定时：key.every(毫秒, key => { … })，按键离开屏幕自动停止 · await M18.sleep(毫秒)

系统：M18.hotkey("ctrl+c") · M18.type("文字", 回车?) · M18.launch("C:\\路径\\程序.exe") · M18.openUrl(网址) · M18.media("playpause")（next / prev / mute / volup / voldown）

联网：const r = await M18.http(网址, { method, headers, body }) → r.status · r.text · r.json()（由控制台代发，不受跨域限制）

调试：M18.log(…) 输出到下方日志。想让 AI 帮你写？点右上角「接入 AI」。

说明

  • 通过 Mirabox 官方 SDK 直接控制硬件，不经过官方 Stream Dock 软件。
  • 官方驱动运行时本控制台会自动退让，退出后自动接管。
  • 拖入图片 = 换该键画面；拖入程序 / 快捷方式 / 脚本 / 文件夹 = 绑定动作。
  • 左侧图标库可直接拖到按键上；三个导航键默认 上/主/下页。
