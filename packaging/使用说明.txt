Stream Dock M18 控制台（绿色版）使用说明
==========================================

一、需要什么
  · Windows 10 / 11（64 位）
  · Microsoft Edge（系统自带；灯效和网页插件要用它在后台运行）
  · Stream Dock M18 设备
  · 不需要安装 Python、Node.js、官方 Stream Dock 软件或任何 SDK：
    和设备通信的官方 WebSocket SDK 已经在 ws-sdk 文件夹里

二、开始使用
  1. 把压缩包「全部解压」到一个普通文件夹（不要在压缩包里直接双击运行）
  2. 插上 M18，双击 M18Console.exe，控制台会在浏览器里打开
  3. 顶栏显示「已连接」即可；默认带了 4 个场景：WINDOWS 控制 / 打击垫（灯效）/ 相册 1 / 音乐控制台
  4. 想要桌面图标：右键 M18Console.exe →「发送到 → 桌面快捷方式」
  ※ ws-sdk、mcp、_internal 文件夹要和 M18Console.exe 放在一起，别单独拿走 exe

三、连不上设备时
  1. 换个 USB 口 / 重新插拔数据线
  2. 关掉官方 Stream Dock 软件（任务栏右下角托盘里也要退出）：两者会抢设备
  3. 确认是完整解压后运行的，ws-sdk\StreamDockWebsocketSDK.exe 存在
  4. 安全软件弹窗拦截时选择「允许」，或把整个文件夹加入信任区
  5. 仍不行：控制台右上「设备设置」里有「重新连接并接管」和「拔插设备（软件）」

四、数据保存在哪
  · 配置、场景、图片、灯效：%APPDATA%\M18Console
  · 程序文件夹可以随便搬、随便删，数据不受影响；升级时解压新版本运行即可
  · 彻底清除：删程序文件夹 + 删 %APPDATA%\M18Console

五、可选
  · 装过官方 Stream Dock 软件的，可点侧栏「同步官方」导入官方的场景、图标包和插件（没装也不影响使用）
  · 让 AI 帮你写插件 / 灯效：控制台「自制插件 → 接入 AI」，或「自制灯效 → 打开技术文档」
