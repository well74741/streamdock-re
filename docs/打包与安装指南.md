# 打包与安装指南

## 一、安装（给使用者）

### 系统要求

- Windows 10 / 11 64 位
- Microsoft Edge（系统自带）
- Stream Dock M18 设备
- **不需要**安装 Python，也**不需要**官方 Stream Dock 软件（设备驱动用的是安装包自带的官方 WebSocket SDK）

### 安装步骤

1. 双击 `M18Console-Setup-<版本>.exe`
2. 如果 Windows 提示「已保护你的电脑」（安装包没有数字签名），点「更多信息 → 仍要运行」
3. 按提示选择安装位置（默认 `%LOCALAPPDATA%\Programs\M18 Console`，**不需要管理员权限**），点「安装」
4. 装完后开始菜单和桌面上会有「Stream Dock M18 控制台」，双击即可打开

### 首次使用

- 插上 M18，控制台会自动连接；顶栏显示「已连接」即可
- 如果电脑上同时开着官方 Stream Dock 软件，两者会抢设备，建议只开一个
- 装过官方软件的，可以点侧栏「同步官方」导入官方的场景、图标包和插件；导入后存在本地，卸载官方软件也不受影响

### 用户数据在哪里

| 内容 | 位置 |
|---|---|
| 配置、场景、上传的图片、自制插件、相册 | `%APPDATA%\M18Console` |
| 程序本体 | 安装目录（默认 `%LOCALAPPDATA%\Programs\M18 Console`） |

升级时直接运行新版安装包覆盖安装即可，用户数据不会丢。

### 卸载

- 「设置 → 应用 → 已安装的应用」里找到「Stream Dock M18 控制台」卸载，或运行安装目录里的 `uninstall.exe`
- 卸载时可以选择是否保留用户数据

### 命令行（批量部署 / 测试用）

```bat
:: 静默安装
M18Console-Setup-1.0.0.exe --silent [--dir 安装目录] [--no-shortcut] [--no-launch]

:: 静默卸载（--purge 同时删除用户数据）
"%LOCALAPPDATA%\Programs\M18 Console\uninstall.exe" --uninstall --silent [--purge]
```

### 接入 AI（可选）

控制台「自制插件」区右上角点「接入 AI」，复制对应客户端（Codex / DeepSeek Harness / Claude / Cursor）的配置即可。
安装版的 MCP 程序是安装目录里的 `m18-mcp.exe`。详见 [AGENTS.md](../AGENTS.md)。

## 二、打包（给开发者）

### 准备（只需一次）

1. 安装 Python 3.9+，安装时勾选 **Add to PATH** 和 **tcl/tk**（安装程序界面用 tkinter）
2. 安装依赖：
   ```bash
   pip install pillow pyinstaller
   ```
3. 把官方 WebSocket SDK 放到项目根目录 `ws-sdk\`，确认存在 `ws-sdk\StreamDockWebsocketSDK.exe`
   （仓库里不含这个二进制文件，缺了打包会直接报错退出）

### 改版本号（可选）

编辑 `app\version.py` 里的 `VERSION = "1.0.0"`，安装包文件名会跟着变。
每次发给别人新版本前建议加一下版本号，方便区分。

### 打包

在项目根目录运行：

```bash
python packaging/build.py
```

几分钟后看到这一行即成功：

```
✓ 安装包：…\dist\release\M18Console-Setup-1.0.0.exe（约 52 MB）
```

脚本依次做的事：

1. PyInstaller 把 `app/server.py` 打成文件夹版程序 `dist\M18Console\`（含 Python 运行时、界面、默认壁纸）
2. 把 `ws-sdk\` 复制到程序旁边
3. 打包卸载程序 `uninstall.exe`
4. 打包 AI 接口 `m18-mcp.exe`，并附上 `AGENTS.md`、`plugin_guide.md`
5. 整个程序文件夹压成 `payload.zip`，再和安装程序一起打成单文件 `Setup.exe`

### 产物

| 路径 | 说明 |
|---|---|
| `dist\release\M18Console-Setup-<版本>.exe` | **发给别人的就是这一个文件** |
| `dist\M18Console\` | 未打包的程序，可直接运行里面的 `M18Console.exe` 试用 |
| `build\` | 临时文件，可删除 |

### 打包后自测（建议）

```bat
:: 装到临时目录、不建快捷方式、不自动启动
dist\release\M18Console-Setup-1.0.0.exe --silent --dir "%TEMP%\m18test" --no-shortcut --no-launch
"%TEMP%\m18test\M18Console.exe"
:: 确认没问题后卸载
"%TEMP%\m18test\uninstall.exe" --uninstall --silent
```

注意：静默安装到临时目录会覆盖「应用」列表里的卸载登记，测试完记得卸载。

### 常见问题

| 现象 | 处理 |
|---|---|
| 报错「文件被占用」/ PermissionError | 打包会先删除旧的 `dist\`、`build\`：先关掉从 `dist\M18Console` 运行的控制台，终端和资源管理器也不要停在 `dist` 文件夹里 |
| `UnicodeEncodeError: 'gbk'` | 先执行 `set PYTHONUTF8=1` 再打包 |
| 缺少 `ws-sdk\StreamDockWebsocketSDK.exe` | 从 Mirabox 官方 SDK 包解压到项目根目录 `ws-sdk\` |
| 杀毒软件误报 | PyInstaller 打包的程序偶尔被误报，加入信任或改用文件夹版 `dist\M18Console\` |
