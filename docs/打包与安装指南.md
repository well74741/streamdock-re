# 打包与安装指南（绿色版）

本项目只出**绿色版**（`M18Console-Portable-<版本>.zip`）：解压即用、不写注册表、不建快捷方式、
不需要管理员权限，放到哪个目录都能跑。**不再提供 Setup 安装程序**。

## 一、使用（给拿到 zip 的人）

### 系统要求

- Windows 10 / 11 64 位
- Microsoft Edge（系统自带）
- Stream Dock M18 设备
- **不需要**安装 Python，也**不需要**官方 Stream Dock 软件（设备驱动用的是包里自带的官方 WebSocket SDK）

### 怎么用

1. 把 `M18Console-Portable-<版本>.zip` 解压到一个普通文件夹（**不要在压缩包里直接双击运行**）
2. 双击解压出来的 `M18Console.exe`，控制台会在浏览器里打开
3. 想放到开始菜单 / 桌面：右键 `M18Console.exe` → 「发送到 → 桌面快捷方式」自己建一个即可
   （绿色版不会自动建快捷方式，这样换目录、删目录都不会留下垃圾）
4. 不想用了：直接删掉整个文件夹

### 首次使用

- 插上 M18，控制台会自动连接；顶栏显示「已连接」即可
- 如果电脑上同时开着官方 Stream Dock 软件，两者会抢设备，建议只开一个
- 装过官方软件的，可以点侧栏「同步官方」导入官方的场景、图标包和插件；导入后存在本地，卸载官方软件也不受影响
- 没装官方软件的电脑：内置的图标包、28 个官方「内置功能」插件、默认场景（相册1 + 音乐控制台）都还能用，
  点「同步官方」会直接提示「没有检测到官方 Stream Dock 驱动」

### 用户数据在哪里

| 内容 | 位置 |
|---|---|
| 配置、场景、上传的图片、相册、日志 | `%APPDATA%\M18Console`（默认） |
| 程序本体 | 你解压出来的那个文件夹 |

- 程序文件夹可以随便搬、随便删，**用户数据不受影响**
- 如果 `%APPDATA%` 写不进去（受控文件夹访问等），程序会自动改用程序旁边的 `data` 文件夹存数据
- 想彻底清干净：删程序文件夹 + 删 `%APPDATA%\M18Console`

### 升级

把新版本的 zip 解压到**另一个文件夹**（或先退出控制台再覆盖），双击新的 `M18Console.exe` 即可。
配置和场景在 `%APPDATA%\M18Console`，覆盖程序不会丢。

### 提示「对路径…的访问被拒绝」/ PermissionError

说明这台电脑**按程序**限制写文件：签名的程序（比如 Python）能写，我们这种没有数字签名的程序在哪儿都写不了。
常见来源：

- **Windows 安全中心的「受控文件夹访问」（勒索软件防护）**
- **第三方安全软件**把未知程序放进了「不受信任」组（卡巴斯基、360、火绒、公司终端管理软件等）

处理：

1. 双击项目根目录的 **`诊断.bat`**：列出这台电脑的安全软件、受控文件夹访问是否开启、最近的拦截记录；
   如果是受控文件夹访问，会询问后一键把 `M18Console.exe` 加入允许列表（需要管理员确认）。
   也可以把 `M18Console.exe` 直接拖到 `诊断.bat` 上
2. 第三方安全软件：在它的「信任区 / 白名单 / 排除项」里添加解压出来的文件夹，并检查「隔离区」
3. 实在放行不了（比如公司电脑没权限改）：这台电脑上用**源码版**（双击「启动 M18 控制台.bat」），
   Python 是签名程序，不会被拦

### 绿色版和源码版可以同时用吗

可以，互不覆盖，但**同一时间只会运行一个**（都用 8642 端口，先启动的那个生效，后启动的只会打开它的窗口）：

| | 源码版（双击「启动 M18 控制台.bat」） | 绿色版（解压后双击 M18Console.exe） |
|---|---|---|
| 数据目录 | 项目里的 `app\` | `%APPDATA%\M18Console` |
| 开机自启 | 在控制台里开「开机自启」即可，两者各自独立 | 同左 |

需要搬配置可以用「更多设置 → 导出 / 导入」或场景右键「导出场景…」。

### 接入 AI（可选）

控制台「自制插件」区右上角点「接入 AI」，复制对应客户端（Codex / DeepSeek Harness / Claude / Cursor）的配置即可。
绿色版的 MCP 程序是解压目录里的 `mcp\m18-mcp.exe`。详见 [AGENTS.md](../AGENTS.md)。

## 二、打包（给开发者）

### 最简单：双击「打包.bat」

项目根目录的 `打包.bat` 会一步步引导：

1. 找 Python 3.9+；没有的话用 winget 自动安装（或打开 python.org 下载页）
2. 检查 Pillow、PyInstaller；缺了会询问后自动 `pip install`（官方源失败自动换清华镜像）
3. 检查官方 WebSocket SDK；缺的话说明放哪儿，并可打开 SDK 下载页
4. 发现 dist 里的控制台正在运行（会导致文件被占用），询问后自动退出它
5. 打包，完成后自动打开 `dist\release` 文件夹

命令行用法：

```bash
python packaging/build.py            # 检查环境 → 缺什么引导装什么 → 打包
python packaging/build.py --yes      # 缺的依赖不问，直接装
python packaging/build.py --check    # 只检查环境，不打包
python packaging/build.py --release  # 公开发布：仅采用 Git HEAD 中已提交的默认预设
```

公开上传包建议用 `--release`，并在构建前先提交代码。这个模式不连接本机控制台、不导出当前场景，
也不采用未提交的本地预设或图标；Git 必须可用。普通打包仍保留原有的本机场景导出流程。

### 手动准备（不用 打包.bat 时）

1. 安装 Python 3.9+，安装时勾选 **Add to PATH**
2. 安装依赖：
   ```bash
   pip install pillow pyinstaller
   ```
3. 把官方 WebSocket SDK 放到项目根目录 `ws-sdk\`，确认存在 `ws-sdk\StreamDockWebsocketSDK.exe`
   （仓库里不含这个二进制文件，缺了打包会直接报错退出）

### 改版本号（可选）

编辑 `app\version.py` 里的 `VERSION = "1.0.0"`，zip 文件名会跟着变。
每次发给别人新版本前建议加一下版本号，方便区分。

### 打包

在项目根目录运行：

```bash
python packaging/build.py
```

几分钟后看到这一行即成功：

```
✓ 绿色版：…\dist\release\M18Console-Portable-1.0.0.zip（45.3 MB，用时 12 秒，解压后运行 M18Console.exe）
```

脚本依次做的事：

1. PyInstaller 把 `app/server.py` 打成文件夹版程序 `dist\M18Console\`（含 Python 运行时、界面、默认壁纸、内置插件、默认场景）
2. 把 `ws-sdk\` 复制到程序旁边
3. 打包 AI 接口 `mcp\m18-mcp.exe`（文件夹版），并附上 `AGENTS.md`、`plugin_guide.md`
4. 整个程序文件夹压成 `dist\release\M18Console-Portable-<版本>.zip`

整个过程**不产生「单文件 exe」**：单文件 exe 启动时要先解压到临时目录，部分电脑的安全软件会拦截
（报 `Could not create temporary directory` / `failed to create runtime-tmpdir`）。
也不编译任何安装程序，所以不需要 .NET Framework 的 C# 编译器。

### 产物

| 路径 | 说明 |
|---|---|
| `dist\release\M18Console-Portable-<版本>.zip` | **发给别人的就是这一个文件**（解压即用） |
| `dist\M18Console\` | 未压缩的程序，可直接运行里面的 `M18Console.exe` 试用 |
| `build\` | 临时文件，可删除 |

### 打包后自测（建议）

```bat
:: 解压到临时目录试跑（不污染 %APPDATA% 里的正式配置）
mkdir "%TEMP%\m18test"
tar -xf dist\release\M18Console-Portable-1.0.0.zip -C "%TEMP%\m18test"
"%TEMP%\m18test\M18Console.exe"
:: 确认没问题后删掉
rmdir /s /q "%TEMP%\m18test"
```

### 常见问题

| 现象 | 处理 |
|---|---|
| 报错「文件被占用」/ PermissionError | 打包会先删除旧的 `dist\`、`build\`：先关掉从 `dist\M18Console` 运行的控制台，终端和资源管理器也不要停在 `dist` 文件夹里 |
| `UnicodeEncodeError: 'gbk'` | 先执行 `set PYTHONUTF8=1` 再打包 |
| 缺少 `ws-sdk\StreamDockWebsocketSDK.exe` | 从 Mirabox 官方 SDK 包解压到项目根目录 `ws-sdk\` |
| 杀毒软件误报 | PyInstaller 打包的程序偶尔被误报，加入信任即可 |
| 解压后双击没反应 | 先看 `%APPDATA%\M18Console\server.log`（或程序旁边 `data\server.log`）最后几行 |
