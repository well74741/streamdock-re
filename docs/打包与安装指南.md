# 打包与安装指南

## 一、安装（给使用者）

### 系统要求

- Windows 10 / 11 64 位
- Microsoft Edge（系统自带）
- Stream Dock M18 设备
- **不需要**安装 Python，也**不需要**官方 Stream Dock 软件（设备驱动用的是安装包自带的官方 WebSocket SDK）

### 安装包和免安装版

打包会同时产出两个文件，一般发安装包；对方装不上（比如弹「Could not create temporary directory」）时发免安装版：

| 文件 | 用法 |
|---|---|
| `M18Console-Setup-<版本>.exe` | 双击安装，有开始菜单 / 桌面快捷方式、可在「应用」里卸载 |
| `M18Console-Portable-<版本>.zip` | 解压到任意文件夹（不要在压缩包里直接运行），双击 `M18Console.exe`；不想用了删掉文件夹即可 |

### 安装步骤

1. 双击 `M18Console-Setup-<版本>.exe`
2. 如果 Windows 提示「已保护你的电脑」（安装包没有数字签名），点「更多信息 → 仍要运行」
3. 按提示选择安装位置（默认 `%LOCALAPPDATA%\Programs\M18 Console`，**不需要管理员权限**），点「安装」
4. 装完后开始菜单和桌面上会有「Stream Dock M18 控制台」，双击即可打开

### 首次使用

- 插上 M18，控制台会自动连接；顶栏显示「已连接」即可
- 如果电脑上同时开着官方 Stream Dock 软件，两者会抢设备，建议只开一个
- 装过官方软件的，可以点侧栏「同步官方」导入官方的场景、图标包和插件；导入后存在本地，卸载官方软件也不受影响

### 用户数据在哪里

| 内容 | 位置 |
|---|---|
| 配置、场景、上传的图片、自制插件、相册 | `%APPDATA%\M18Console` |
| 程序本体 | 安装目录（默认 `%LOCALAPPDATA%\Programs\M18 Console`） |

升级时直接运行新版安装包覆盖安装即可，用户数据不会丢。

### 打开安装包弹「Could not create temporary directory!」

（还有一种是「LOADER: failed to create runtime-tmpdir path … 拒绝访问」）

旧版安装包是 PyInstaller「单文件 exe」，启动时要先把自己解压到临时目录，被安全软件拦截就会弹这两种错。

- **新版安装包已彻底改掉**：安装程序换成原生 .NET 程序，不再解压到任何临时目录；AI 接口也改成文件夹版
- 新版还是被拦：把安装包加入安全软件信任，或改用**免安装版 zip**
- 系统临时目录本身也可能坏了：「运行」里输入 `%TEMP%` 打开，看能否新建文件；不能的话在「属性 → 安全」里给自己加「完全控制」

### 换任何路径都提示「对路径…的访问被拒绝」/ 免安装版报 PermissionError

说明这台电脑**按程序**限制写文件：签名的程序（比如 Python）能写，我们这种没有数字签名的程序在哪儿都写不了。
常见来源：

- **Windows 安全中心的「受控文件夹访问」（勒索软件防护）**
- **第三方安全软件**把未知程序放进了「不受信任」组（卡巴斯基、360、火绒、公司终端管理软件等）

处理：

1. 双击项目根目录的 **`诊断.bat`**：列出这台电脑的安全软件、受控文件夹访问是否开启、最近的拦截记录；
   如果是受控文件夹访问，会询问后一键把安装包和 `M18Console.exe` 加入允许列表（需要管理员确认）。
   也可以把安装包 / exe 直接拖到 `诊断.bat` 上
2. 第三方安全软件：在它的「信任区 / 白名单 / 排除项」里添加安装包和安装目录，并检查「隔离区」
3. 实在放行不了（比如公司电脑没权限改）：这台电脑上用**源码版**（双击「启动 M18 控制台.bat」），
   Python 是签名程序，不会被拦

新版安装包和控制台被拦时会直接弹出上面这些说明，不再只有一句「拒绝访问」或一段 Python 报错；
免安装版在 `%APPDATA%` 写不进去时，会自动改用程序旁边的 `data` 文件夹存数据。

### 源码版和安装版可以同时装吗

可以，互不覆盖，但**同一时间只会运行一个**：

| | 源码版（双击「启动 M18 控制台.bat」） | 安装版（开始菜单 / 桌面快捷方式） |
|---|---|---|
| 数据目录 | 项目里的 `app\` | `%APPDATA%\M18Console` |
| 开机自启快捷方式 | `Stream Dock M18 控制台（源码版）.lnk` | `Stream Dock M18 控制台.lnk` |

- 两个版本共用 8642 端口：先启动的那个生效，后启动的只会打开先启动那个的窗口，并弹出提示
  「你打开的是 X 版，但 Y 版已经在运行」。要换版本，先在「设备设置 → 退出控制台」
- 两个版本的配置、场景各存各的，所以切换版本后看到的按键不一样是正常的；
  需要搬配置可以用「更多设置 → 导出 / 导入」或场景右键「导出场景…」
- 开机自启只保留一个：在哪个版本里打开「开机自启」，就会换成那个版本，另一个的自启自动去掉。
  左下角版本号后面会写当前是「源码版」还是「安装版」，鼠标悬停能看到数据目录
- 卸载安装版只会删安装版自己的开机自启，不影响源码版；安装 / 卸载时也只会退出安装版，正在运行的源码版不受影响

### 卸载

- 「设置 → 应用 → 已安装的应用」里找到「Stream Dock M18 控制台」卸载，或运行安装目录里的 `uninstall.exe`
- 卸载时可以选择是否保留用户数据

### 命令行（批量部署 / 测试用）

```bat
:: 静默安装
M18Console-Setup-1.0.0.exe --silent [--dir 安装目录] [--no-shortcut] [--no-launch]

:: 静默卸载（--purge 同时删除用户数据）
"%LOCALAPPDATA%\Programs\M18 Console\uninstall.exe" --uninstall --silent [--purge]
```

### 接入 AI（可选）

控制台「自制插件」区右上角点「接入 AI」，复制对应客户端（Codex / DeepSeek Harness / Claude / Cursor）的配置即可。
安装版的 MCP 程序是安装目录里的 `mcp\m18-mcp.exe`。详见 [AGENTS.md](../AGENTS.md)。

## 二、打包（给开发者）

### 最简单：双击「打包.bat」

项目根目录的 `打包.bat` 会一步步引导：

1. 找 Python 3.9+；没有的话用 winget 自动安装（或打开 python.org 下载页）
2. 检查 C# 编译器（Windows 自带）、Pillow、PyInstaller；缺 Pillow / PyInstaller 会询问后自动 `pip install`（官方源失败自动换清华镜像）
3. 检查官方 WebSocket SDK；缺的话说明放哪儿，并可打开 SDK 下载页
4. 发现 dist 里的控制台正在运行（会导致文件被占用），询问后自动退出它
5. 打包，完成后自动打开 `dist
elease` 文件夹

命令行用法：

```bash
python packaging/build.py            # 检查环境 → 缺什么引导装什么 → 打包
python packaging/build.py --yes      # 缺的依赖不问，直接装
python packaging/build.py --check    # 只检查环境，不打包
```

### 手动准备（不用 打包.bat 时）

1. 安装 Python 3.9+，安装时勾选 **Add to PATH**
2. 安装依赖：
   ```bash
   pip install pillow pyinstaller
   ```
3. 把官方 WebSocket SDK 放到项目根目录 `ws-sdk\`，确认存在 `ws-sdk\StreamDockWebsocketSDK.exe`
   （仓库里不含这个二进制文件，缺了打包会直接报错退出）

### 改版本号（可选）

编辑 `app\version.py` 里的 `VERSION = "1.0.0"`，安装包文件名会跟着变。
每次发给别人新版本前建议加一下版本号，方便区分。

### 打包

在项目根目录运行：

```bash
python packaging/build.py
```

几分钟后看到这一行即成功：

```
✓ 安装包：…\dist\release\M18Console-Setup-1.0.0.exe（约 52 MB）
```

脚本依次做的事：

1. PyInstaller 把 `app/server.py` 打成文件夹版程序 `dist\M18Console\`（含 Python 运行时、界面、默认壁纸）
2. 把 `ws-sdk\` 复制到程序旁边
3. 打包 AI 接口 `mcp\m18-mcp.exe`（文件夹版），并附上 `AGENTS.md`、`plugin_guide.md`
4. 整个程序文件夹压成 `payload.zip`（同时复制一份作为免安装版）
5. 用 Windows 自带的 C# 编译器编译 `packaging\Setup.cs`（原生安装 / 卸载程序），把 `payload.zip` 附加在它末尾，得到 `Setup.exe`

整个过程**不产生「单文件 exe」**：单文件 exe 启动时要先解压到临时目录，部分电脑的安全软件会拦截。
安装程序是原生 .NET 程序，直接从自身读出程序文件解压到安装目录；装好后自己写一份不带载荷的 `uninstall.exe`。

### 产物

| 路径 | 说明 |
|---|---|
| `dist\release\M18Console-Setup-<版本>.exe` | **发给别人的就是这一个文件** |
| `dist\release\M18Console-Portable-<版本>.zip` | 免安装版，安装包在对方电脑上打不开时用 |
| `dist\M18Console\` | 未打包的程序，可直接运行里面的 `M18Console.exe` 试用 |
| `build\` | 临时文件，可删除 |

### 打包后自测（建议）

```bat
:: 装到临时目录、不建快捷方式、不自动启动
dist\release\M18Console-Setup-1.0.0.exe --silent --dir "%TEMP%\m18test" --no-shortcut --no-launch
"%TEMP%\m18test\M18Console.exe"
:: 确认没问题后卸载
"%TEMP%\m18test\uninstall.exe" --uninstall --silent
```

注意：静默安装到临时目录会覆盖「应用」列表里的卸载登记，测试完记得卸载。

### 常见问题

| 现象 | 处理 |
|---|---|
| 报错「文件被占用」/ PermissionError | 打包会先删除旧的 `dist\`、`build\`：先关掉从 `dist\M18Console` 运行的控制台，终端和资源管理器也不要停在 `dist` 文件夹里 |
| `UnicodeEncodeError: 'gbk'` | 先执行 `set PYTHONUTF8=1` 再打包 |
| 缺少 `ws-sdk\StreamDockWebsocketSDK.exe` | 从 Mirabox 官方 SDK 包解压到项目根目录 `ws-sdk\` |
| 找不到 csc.exe | 编译安装程序用 Windows 自带的 .NET Framework 4 编译器；在「启用或关闭 Windows 功能」里勾选 .NET Framework 4.8 |
| 杀毒软件误报 | PyInstaller 打包的程序偶尔被误报，加入信任或改用免安装版 |
