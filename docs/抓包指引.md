# 抓取官方驱动 USB 流量（用于复刻输入初始化）

目标：拿到官方 Stream Dock 启动时发给设备的**初始化序列**，以及按键时的上报格式。
目前我们自己的程序打开设备后，两个 HID 接口都收不到任何按键包，说明设备没有被正确"启动"。

## 一、准备（约 5 分钟）

1. 下载 **USBPcap**：<https://desowin.org/usbpcap/>
   - 安装时勾选 "Install USBPcap"（会装一个抓包驱动，需要管理员权限）
   - 安装完建议重启一次
2. 安装 **Wireshark**（如果还没有）：<https://www.wireshark.org/>
   - 安装时勾选 "Install USBPcap" 也可以，二选一

## 二、抓包（约 3 分钟）

1. 先**完全退出**我们的控制台（设备页 → 退出控制台），也退出官方软件
2. 打开 Wireshark，在网卡列表里找到 **USBPcap1 / USBPcap2 / USBPcap3** 这类接口
   - 不确定是哪个没关系，选 **USBPcap1** 先试
3. 双击开始抓包，然后在过滤器里输入：
   ```
   usb.idVendor == 0x6603
   ```
4. 保持抓包，**启动官方 Stream Dock 软件**，等它把设备点亮（约 10 秒）
5. 按设备上的 **11 号键 3 次**，再按 **左中右三个导航键各 1 次**
6. 停止抓包（红色方块），另存为 `official.pcapng`

## 四、如果 USBPcap 抓不到

有些主板/驱动组合下 USBPcap 抓不到 HID 设备。备选方案：

- 用 **Windows 事件跟踪（ETW）** 抓 HID：`logman` + `Microsoft-Windows-USB-USBPORT` provider
- 或者用一台 Linux 机器（树莓派即可）+ `usbmon` 抓
